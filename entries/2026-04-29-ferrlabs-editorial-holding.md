The FerrLabs holding site is now fully on the editorial design language we use across product sites. Major visual changes:

- **Paper palette + Fraunces** — soft `#faf8f4` background, slate ink, Fraunces 900 display headlines, DM Mono for eyebrows.
- **List products layout** — each product gets its own row (`№ NN — name — tagline — long description — badge`), generous typography, no more cards.
- **Scroll-blur navbar** — sticky at top, `backdrop-filter: blur(14px)` always on so the typography behind it stays readable.
- **Sticky-bottom footer** — fixed an old bug where the footer floated mid-page on short routes.
- **Hairline section dividers** + numbered eyebrows (`№ 01 — HERO`, `№ 02 — PRODUCTS`, …).

Same information, distinct typographic identity from every Tailwind-default SaaS landing page.
