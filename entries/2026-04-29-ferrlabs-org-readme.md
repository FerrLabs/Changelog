The `FerrLabs/.github` repo renders the README at `github.com/FerrLabs`. It was a stub. It now properly introduces the org to anyone landing there from GHCR, a starred repo, or a Google search:

- Short pitch: what FerrLabs is (small studio, five products, one-person team).
- One paragraph per **public** product (FerrFlow, FerrVault, FerrTrack, FerrGrowth, FerrGames) with the link to the marketing site.
- Status table: what's GA, what's beta, what's still a placeholder.
- Footer with contact + brand colors.

Internal tooling and staff-only repos are intentionally not listed.
