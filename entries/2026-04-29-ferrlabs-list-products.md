The Products section on ferrlabs.com switched from the asymmetric card grid (one large FerrFlow card + three small ones) to a list layout that better matches the editorial direction.

Each product is now a row in a 4-column grid: `№ XX | name + tagline | description + long copy + cta | badge`. Fraunces 64px display name with the accent dot, hairline rules between rows. Lighter visual weight, easier to scan, more text-driven.
